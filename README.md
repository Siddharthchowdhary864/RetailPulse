# RetailPulse 2.0 – E-commerce Sales & Customer Intelligence Analysis

## Project Overview
This project analyses an online retail dataset to understand sales performance, product performance and customer purchasing behaviour.

The analysis was performed using Python and its data analysis libraries in Google Colab.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Dataset
UCI Online Retail Dataset

The dataset contains transaction records from a UK-based online retail business covering December 2010 to December 2011.

## Project Objectives
- Analyse overall sales performance.
- Identify monthly sales trends.
- Compare sales across countries.
- Identify top-performing products.
- Understand customer purchasing behaviour.
- Segment customers using RFM analysis.

## Project Work
1. Dataset Understanding
2. Exploratory Data Analysis (EDA)
3. Data Cleaning and Preparation
4. Sales Performance Analysis
5. Product Performance Analysis
6. Customer Behaviour Analysis
7. RFM Customer Segmentation
8. Data Visualisation
9. Business Insights and Recommendations

## Key Findings
- The United Kingdom generated the highest revenue.
- November recorded the highest monthly sales.
- Regency Cakestand 3 Tier was the highest-revenue product.
- Approximately 70% of customers were repeat customers.
- Hibernating customers formed the largest RFM segment.
